# Glosses: руководство пользователя

## Что делает расширение

<img width="1280" height="798" alt="image" src="https://github.com/user-attachments/assets/b83a248b-e504-4931-bf69-6a4fad092c0f" />


Glosses добавляет в [SillyTavern](https://github.com/SillyTavern/SillyTavern) литературные сноски: после каждого ответа ИИ расширение находит в посте слова и генерирует для них сноски в выбранном стиле — пратчеттовская, языковая, академическая, метанарративная, гибридная (комбинация) или ваша собственная.

Сноски привязываются к тексту поста, свайпы хранят свои сноски независимо друг от друга. Одно исключение: если сохранённый набор сносок опознан как принадлежащий ДРУГОМУ свайпу того же поста (следствие внутреннего клонирования `extra` в SillyTavern — на практике бывает, когда у вариантов идентичный текст), такой набор не пересаживается на чужие слова, а вариант перегенерируется заново автоматически (если автогенерация включена и источник API настроен).

## Установка

1. Скопируйте папку расширения в `data/default-user/extensions/third-party/` и перезапустите SillyTavern.
2. Откройте панель расширений → **Glosses** → включите **Enable Footnotes**.
3. В аккордеоне **Промпт** выберите пресет:

   | Пресет | Что задаёт |
   |---|---|
   | **Pratchett 50 (RU)** | стиль `pratchett50`, язык сносок `ru` |
   | **Lang EN → RU · A2** | стиль `language`, язык `ru`, целевой язык `en`, уровень A1–A2 |
   | **Academic Lore (RU)** | стиль `academic`, язык `ru` |
   | **Meta (RU)** | стиль `meta_plus`, язык `ru` |

Я советую попробовать гибридный тип сносок: 

<img width="648" height="824" alt="image" src="https://github.com/user-attachments/assets/ad3baded-d3d2-496e-8866-c67a5e687199" />


5. В аккордеоне **Источник генерации**:
   - **Connection Profile** (рекомендуется) — используется профиль расширения ST Connection Manager;
   - **Custom (OpenAI-compatible)** — свой endpoint и ключ. Запрос идёт прямо из браузера: endpoint должен отдавать CORS-заголовки. Ключ хранится в браузерном `localforage` — для чувствительных ключей предпочтителен Connection Profile. `http:`-endpoint вне localhost требует одноразового подтверждения origin.

## Использование

### Чтение сносок

<img width="802" height="338" alt="image" src="https://github.com/user-attachments/assets/31d8cd7a-1d24-4d72-a91f-3eb5c4464379" />

Режимы отображения (аккордеон **Отображение**):

| Режим | Маркеры в тексте | Попап по клику | Блок под постом |
|---|---|---|---|
| `inline` | есть (без надстрочных) | нет | да — нумерованный список |
| `popup` | есть (надстрочные цифры) | да | нет |
| `both` | есть (надстрочные цифры) | да | да |
| `panel` | нет | нет | нет — сноски только в плавающей панели |

Клик по маркеру в режимах `popup`/`both` открывает всплывающий попап со сноской. В режиме `panel` в чате не рисуется ничего: маркеры убираются, а плавающая панель включается принудительно — сноски читаются только в ней.

### Свой CSS (для продвинутых)

Настройки в «Popup style» покрывают большинство задач; когда их не хватает, попап можно стилизовать сырым CSS: **Display → Custom CSS → Edit CSS**.

- Стилевой лист ложится **поверх** выбранного скина и настроек — можно подкрутить один цвет скина или собрать попап с нуля.
- Правки применяются живьём — превью в настройках и любой открытый попап сноски реагируют, пока вы печатаете. Закрытие редактора работу не теряет.
- **Insert base template** даёт стартовый закомментированный план всех целевых классов (`.gls-popup`, `.gls-popup-title`, `.gls-popup-text`, …) и токенов (`--gls-popup-radius`, `--gls-surface`, …).
- Галочка отключает слой, не удаляя текст.
- Если строка статуса сообщает, что правила не распознаны, проверьте баланс фигурных скобок (ок, да?).

### Плавающая панель

За панелью с тремя вкладками следует фокусируемое сообщение:

- **Сноски** — сноски текущего сообщения: навигация, копирование, правка текста (якоря неизменяемы), удаление, регенерация.
- **По запросу** — построчный список слов/фраз (до 20): расширение создаст сноски в активном стиле и привяжет их к сфокусированному сообщению (маркеры появятся на посте, записи можно править и удалять во вкладке Footnotes). Черновик списка сохраняется вместе с чатом.
- **Исключения** — мягкое предпочтение не повторять уже оглоссенные якоря и точный forced-ignore (per-chat, только на будущие генерации).

✕ прячет панель, и выбор запоминается: после перезагрузки страницы панель останется скрытой, клик по лаунчеру вернёт её, а ещё один клик по лаунчеру при открытой панели отключит плавающую панель совсем. Если источник генерации не настроен, панель покажет постоянный бейдж «Source not configured» с кнопкой открытия настроек.

### Кнопки-лаунчеры

В настройках (Кнопка запуска) выбирается, какие кнопки открывают панель:

- **В панели быстрых ответов** — кнопка `Tⁿ` в баре Quick Replies;
- **Плавающая кнопка** — плавающая круглая кнопка, работающая даже при выключенном Quick Replies. Её можно перетаскивать в любой угол (позиция запоминается и переживает перезапуск браузера), клик открывает/закрывает панель. Кнопка всегда остаётся под интерфейсом SillyTavern — она не перекрывает окна настроек, а из-под топ-бара её вытолкнет автоматический clamp;
- **Обе кнопки** — обе кнопки.

Во время генерации сносок обе кнопки пульсируют.

### Слэш-команды

| Команда | Действие |
|---|---|
| `/glosses_toggle` | Вкл/выкл сноски (кнопка-лаунчер синхронизируется) |
| `/glosses_regen` | Регенерация сносок последнего ответа ИИ |
| `/glosses_clear` | Очистить кэш сносок текущего чата |

## Ограничения

- SillyTavern клиент `1.12.10+`; Connection Manager нужен только для источника Connection Profile.
- Гарантий «честности» для вымышленных языков (High Valyrian, Klingon и т.п.) нет — промпт просит честную аттестацию, выдуманной лексики ожидать не стоит.
- Встроенный Translate extension в режиме замены текста сообщения распознаётся: маркеры и автогенерация для переведённого вида пропускаются, при возврате оригинала кэш восстанавливается.
- Очистка данных (Clean) удаляет кэш сносок чата и загруженный звук, но не трогает API-ключ и позицию плавающей кнопки — они пер-браузерные.
